1.) How to play Bubblet...
--------------------------
Playing Bubblet is very easy! The only thing you have to do is to click at
-at least- two Bubbles of the same color, which are connected to each other.
The more Bubbles aligned together the more Bubble-Points you get! If you click
Bubbles that are connected, they get highlighted. If you click them
again they get bursted. All Bubbles above the bursted ones will fall down.

2.) Different Game-Styles
-------------------------
Bubblet has four Game-Styles which result in different styles of gameplay.
There are:

Normal:
This is the easiest mode in Bubblet. If a row is empty, the hole is shut with
moving the Bubbles together. If there are no destroyable Bubbles left, the game
is over. If you have five or less Bubbles left, you get extra 'Bubble-Points'.

Continuous:
This mode is the same as the normal-mode, with one addition. If a row is empty,
the hole is shut with moving the Bubbles together, and a new, filled, row
appears on the left! In this mode you've the chance to accuire much HIGHER
scores, because it only depends on your skills how long you play...
In this mode you won't receicve any Bubble-Bonuses, because you'll never have
five or less Bubbles left. (The game is over if you have to much 'rubbish' on
the screen to become a new row...)

Shifter:
This mode is also like the normal-mode but with another addition. If there is a
free place to the left of one or more Bubbles in a line, the Bubbles will move
to the right in order to shut this hole...

Megashift:
As the name says, this is an addition to the shifter-mode in which, just like
in continuous-mode, new rows appear on the left...
This mode is VERY HARD to play, but you also may receive the most points here!
