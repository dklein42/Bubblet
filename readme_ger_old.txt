1.) Wie spielt man Bubblet?
---------------------------
Bubblet spielen ist wirklich einfach! Das einzige was Sie tun müssen ist -mindestens-
zwei Bubbles einer Farbe horizontal oder vertikal nebeneinander anklicken. Diese werden
zuerst rot umrandet und mit einem zweiten Click platzen sie dann. Desto mehr Bubbles Sie
auf einmal platzen, desto mehr Punkte gibt es. Das Ziel ist es, so viele Punkte wie
möglich zu erhalten.

2.) Verschiedene Spieltypen
-------------------------
In Bubblet gibt es vier verschiedene Spieltypen. Da währen:

Normal-Mode:
Das ist der einfachste Modus von allen. Bei Spielstart sehen Sie ein volles Spielfeld. Platzen
Sie Bubbles weg, so fallen die evtl. darüber liegenden herunter. Wenn eine Spalte entstehen
sollte, so wird diese geschlossen indem die Spalten zusammenrutschen. Bleiben bei Ende des
Spiels weniger als fünf Bubbles übrig gibt es einen 'Bubbles-Bonus'.

Continuous-Mode:
Der Continuous-Modus ist der am meisten gespielte Modus von Bubblet. Er funktioniert genau
wie der Normal-Mode, nur mit der Ergänzung, dass wenn eine Spalte frei wird, eine neue von links
hinzu kommt. Würde man perfekt spielen, könnte man diesen Modus also 'ewig' spielen.
Normalerweise bleibt aber irgendwann mal soviel 'Müll' übrig, dass keine Möglichkeit mehr besteht,
und somit das Spiel beendet ist.

Shifter-Mode:
Dieser Modus ist auch ähnlich dem Normal-Mode. Nur das in diesem Fall auch Löcher geschlossen
werden, in dem Bubbles von links nach rechts aufrutschen und Löcher schließen.

Megashifter-Mode:
Wie der Name schon sagt, funktioniert der MegaShifter-Mode wie der Shifter-Mode. Allerdings kommen
bei freien Spalten (wie im Continuous-Mode) neue Spalten von links auf das Spielfeld. Die einzelnen
Bubbles rutschen dann jeweils so weit auf bis sie nicht mehr herunter fallen und sich nach rechts
bewegen können (in dieser Reihenfolge). Dieser Modus ist sehr schwierig zu beherschen, dafür kann
man hier aber auch die höchsten Highscores erreichen!
